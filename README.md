# 🎯 QuizMaster Bot

Крутой Telegram-бот для викторин на библиотеке **pyTelegramBotAPI (Telebot)**.

---

## 🚀 Быстрый старт

### 1. Установи зависимости
```bash
pip install -r requirements.txt
```

### 2. Получи токен бота
1. Открой [@BotFather](https://t.me/BotFather) в Telegram
2. Отправь `/newbot` и следуй инструкциям
3. Скопируй токен

### 3. Вставь токен в бот
В файле `bot.py` найди строку:
```python
BOT_TOKEN = "YOUR_BOT_TOKEN_HERE"
```
И замени на свой токен:
```python
BOT_TOKEN = "1234567890:ABCdefGHIjklMNOpqrSTUvwxYZ"
```

### 4. Запусти бота
```bash
python bot.py
```

## ➕ Как добавить свои вопросы

В `bot.py` найди словарь `QUIZ_DATA` и добавь вопросы в нужную категорию:

```python
{
    "question": "Твой вопрос?",
    "options": ["Вариант A", "Вариант B", "Вариант C", "Вариант D"],
    "answer": 0,  # индекс правильного ответа (0 = A, 1 = B...)
    "explanation": "Интересный факт об ответе."
},
```

Или создай новую категорию:
```python
"🎵 Музыка": [
    { "question": "...", "options": [...], "answer": 0, "explanation": "..." },
    ...
]
```
